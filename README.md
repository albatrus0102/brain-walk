# 오늘의 두뇌 산책 (brain-walk)

가족이 함께 응원하는 두뇌 훈련 앱이에요. 훈련하는 분(예: 아버지)은 매일 짧은 두뇌 게임을 하고, 가족은 기록을 보고 응원 메시지와 알림을 보내요.
휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있고(PWA), 서버는 Firebase(무료 사용량 안), 화면은 GitHub Pages에 올려요.

> **의료기기가 아니에요.** 이 앱은 두뇌 활동을 돕는 생활 도구예요. 치매나 경도인지장애를 진단·치료·예방하지 않고, 점수는 의학적 판단의 근거가 아니에요.
> 이 앱은 두뇌 활동을 돕는 훈련용이며 의료기기나 치료를 대신하지 않아요. 걱정되는 점이 있으면 병원에서 상담하세요.

설정은 처음 한 번만 하면 돼요. 코딩을 몰라도 아래 순서대로 따라 하면 됩니다. (약 40분)

## 1. 준비물
- Google 계정 (Firebase용)
- GitHub 계정 (화면을 올리는 곳)
- PC (처음 설정할 때만 필요해요)

## 2. 저장소 만들기
1. 이 저장소를 **Fork** 하거나, "Use this template"으로 내 계정에 복사해요.
2. 이름은 `brain-walk`, 공개 범위는 **Public** 으로 해요. (이름을 바꾸면 주소도 바뀌어요. 이 안내는 `brain-walk` 기준이에요.)

앱 주소는 `https://내아이디.github.io/brain-walk/` 가 돼요.

## 3. Firebase 프로젝트 만들기
1. <https://console.firebase.google.com> 에 들어가 **프로젝트 추가**를 눌러요.
2. 이름을 정하고(예: `brain-walk-우리집`), **Google 애널리틱스는 "사용 안 함"** 으로 해요. 개인정보 수집을 줄이기 위해서예요.

## 4. 웹 앱 등록하고 설정값 복사하기
1. 프로젝트 첫 화면의 `</>` (웹) 아이콘을 눌러요. (또는 프로젝트 설정 ⚙ › 일반 › 내 앱)
2. 앱 닉네임을 쓰고 "Firebase 호스팅"은 **체크하지 않고** 등록해요.
3. 화면에 나오는 `firebaseConfig = { apiKey: "...", authDomain: "...", ... }` 값을 메모장에 복사해 둬요. (9번에서 써요.)

## 5. 익명 로그인 켜기
1. 왼쪽 메뉴 **Authentication** › 시작하기 › **로그인 방법** 탭 › **익명** › 사용 설정 › 저장.
2. (선택) **Google** 도 사용 설정하고, 설정 › **승인된 도메인**에 `내아이디.github.io` 를 추가해요.

> ⚠ "Identity Platform으로 업그레이드"는 **하지 마세요.** 업그레이드하면 30일이 지난 익명 계정이 자동 삭제될 수 있어요.

## 6. Firestore 만들기 (서울)
1. **Firestore Database** › 데이터베이스 만들기.
2. 위치는 **asia-northeast3 (서울)**, 모드는 **프로덕션 모드**로 해요. (위치는 나중에 바꿀 수 없어요.)

## 7. 보안 규칙 넣기
가족이 아닌 사람이 데이터를 보지 못하게 하는 가장 중요한 단계예요.
- **콘솔로 하기(쉬움):** Firestore › **규칙** 탭에서 기존 내용을 모두 지우고, 이 저장소의 `firestore.rules` 파일 내용을 전부 붙여넣은 뒤 **게시**를 눌러요.
- **CLI로 하기:** PC에서 `npm i -g firebase-tools` → `firebase login` → `firebase use 프로젝트ID` → `firebase deploy --only firestore`

규칙을 고치면 `tests/` 의 시험을 꼭 다시 돌려요. ([18번](#18-개발자용-폴더-구조와-시험))

## 8. 푸시 알림 키(VAPID) 만들기
프로젝트 설정 ⚙ › **클라우드 메시징** › 웹 구성 › **웹 푸시 인증서** › **키 쌍 생성** 을 누르고, 나온 **공개 키**를 복사해 둬요.

## 9. firebase-config.js 채우기
1. GitHub 저장소에서 `firebase-config.js` 를 열고 연필 아이콘(편집)을 눌러요.
2. `REPLACE_ME` 자리에 4번의 값(`apiKey`, `authDomain`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`)과 8번의 공개 키(`vapidKey`)를 붙여넣어요.
3. **Commit changes** 를 눌러요.

이 값들은 공개되어도 괜찮아요(웹 설정은 원래 공개용). 단, **서비스 계정 키(JSON)는 절대 이 저장소에 올리면 안 돼요.**

## 10. GitHub Pages 켜고 배포하기
1. 저장소 **Settings › Pages › Build and deployment › Source: GitHub Actions** 로 바꿔요.
2. 배포는 **`main` 브랜치에 올라올 때마다** 자동으로 돼요. 이 작업 브랜치(`claude/digital-cognitive-therapy-app-lff0ze`)에서 작업했다면, **Pull request를 만들어 `main` 에 병합(Merge)** 해요.
3. **Actions** 탭에서 "deploy pages"가 초록색이 되면 `https://내아이디.github.io/brain-walk/` 로 접속해요.
4. 아직 9번을 하지 않았다면 "관리자 설정이 필요해요" 화면이 보여요. 이때 **체험 모드 (이 기기에만 저장)** 로 둘러볼 수 있어요.

## 11. 휴대폰에 설치하기
앱은 홈 화면과 설정의 **앱 설치** 줄에서 휴대폰에 맞는 방법을 알려 줘요. 설치하면 다음부터 아이콘만 누르면 열려요.
- **안드로이드·PC 크롬:** 처음 화면과 홈에 나오는 **📲 홈 화면에 앱 설치** 카드의 **설치하기** 버튼을 눌러요. 설치되면 홈 화면의 '두뇌산책' 아이콘으로 열어요. **닫기**를 누르면 7일 동안 카드를 숨겨요(설정의 "앱 설치"에서는 언제든 다시 할 수 있어요). 카드가 안 보이면 브라우저 메뉴(⋮) › **앱 설치**(또는 홈 화면에 추가).
- **아이폰 (iOS 16.4 이상):** 반드시 **Safari**로 열어요 › 아래 **공유** 버튼(네모에 위쪽 화살표) › **홈 화면에 추가** › 추가 › **홈 화면의 아이콘으로 다시 열기** › 가족 만들기/코드 입력 › 설정에서 **알림 받기**. 앱에도 그림이 있는 번호 안내가 나와요.
  아이폰은 알림을 **홈 화면에 추가한 앱**에서만 받을 수 있고, Safari와 홈 화면 앱은 저장 공간이 따로예요. 그래서 홈 화면 앱을 연 다음에 가입하는 것이 가장 편해요.
- **카카오톡·네이버·인스타그램 등 앱 안에서 열었을 때:** 앱 안 브라우저에서는 설치가 안 돼요. 맨 위 카드의 **크롬으로 열기**(안드로이드) 또는 **기본 브라우저로 열기**(카카오톡)를 누르면 초대 코드(`?join=`)를 그대로 가지고 열려요. 아이폰의 다른 앱은 오른쪽 아래 ⋯ 또는 공유 버튼 › **Safari로 열기**.
- 안드로이드는 설치한 뒤 **알림 허용**을 눌러요.

## 12. 가족 초대하기
1. 처음 쓰는 사람이 **새 가족 만들기**를 눌러 이름과 역할(훈련하는 분 / 가족)을 정해요.
2. 화면에 6글자 **가족 코드**와 **초대 링크**가 나와요. **카톡으로 초대 보내기**를 누르면 초대 문구가 복사돼요. 카톡에 붙여넣어 보내세요.
3. 가족은 링크를 열면 코드가 미리 입력되어 있어요. 이름을 쓰고 **가족**을 선택하면 끝이에요. (링크가 안 열리면 앱에서 **가족 코드로 들어가기**에 코드를 직접 입력해요.)
4. 코드는 **7일** 동안 쓸 수 있어요. 설정 › **가족 코드 다시 보기 / 새로 만들기**에서 다시 볼 수 있어요. 누군가를 내보낸 뒤에는 새 코드를 만드는 것이 좋아요.
5. 코드의 글자는 헷갈리지 않게 `0, O, 1, I`를 쓰지 않아요.

## 12-1. 관리자와 훈련하는 분 화면 설정
훈련하는 분(예: 아버지)의 화면은 **아주 단순하게**, 그 분의 글자 크기·훈련 분량·난이도는 **가족 중 관리자**가 멀리서 정해요. 아버지는 아무것도 누르지 않아도 바뀐 설정이 그 휴대폰에 바로 적용돼요.

**누가 무엇을 할 수 있나요**
| | 방 주인 | 관리자 | 가족 | 훈련하는 분 |
|---|---|---|---|---|
| 훈련 계획·훈련하는 분 화면·알람 바꾸기 | O | O | 보기만 | 보기만(설정은 가족이 도울 때만) |
| 훈련하는 분 정하기, 호칭 바꾸기, 구성원 내보내기 | O | O | X | X |
| 가족 코드 새로 만들기, 다른 가족의 새 기기 연결 코드 | O | O | X | X |
| 관리자 지정/해제, 방 주인 넘기기, 가족방 전체 삭제 | O | X | X | X |
| 설문·병원 검사 기록, 대화, 알림 보내기 | O | O | O | (대화만) |
- 방 주인은 늘 관리자예요. 방 주인이 다른 가족을 **관리자로 정하면**(설정 › 가족 구성원 › 이름 누르기) 그분도 계획과 화면을 바꿀 수 있어요. 관리자는 '가족' 역할의 사람만 될 수 있어요.
- 관리자가 아니면 같은 화면이 **읽기 전용**으로 보이고 "관리자만 바꿀 수 있어요. 관리자: ○○" 라고 알려 줘요.
- **훈련하는 분이 방을 만들었다면** 가족 한 분이 들어온 뒤 설정 › 방 주인 전용 › **관리자 넘기기 (가족방 주인 바꾸기)** 로 방 주인을 넘겨 주세요. (만든 직후 화면에도 이 안내가 나와요.)
- 새로 들어온 사람은 승인 없이 '가족'으로 들어와요(대화에 "○○님이 들어왔어요"가 나와요). 모르는 사람이 들어왔다면 관리자가 설정 › **가족 구성원**에서 **가족방에서 내보내기** 를 하고, 가족 코드를 새로 만들어 주세요.

**훈련 계획** (설정 › ○○ 기기 관리 › 훈련 계획 — 다섯 칸을 눌러 펼쳐요)
- 하루 분량: 하루 게임 수(1~9), 게임당 문제 수(기본 또는 3~10), 목표 시간, 게임 사이 자동 넘김(끔·5·10·15초, 기본 10초). 예상 시간이 목표보다 길면 알려 줘요.
- 훈련 요일과 알람: 요일(월~일), 알람 시간, 휴대폰 캘린더 등록. 알람은 훈련하는 날에만 울려요.
- 게임 고르기와 순서: 날마다 바꾸기(영역을 돌려요) 또는 정한 순서대로, 게임별 켜기/끄기, 오늘·내일 미리보기.
- 난이도: 게임마다 자동(가장 쉬움~가장 어려움 범위) 또는 고정(1~5단계). 자동은 정답률 80% 이상이면 올리고 50% 미만이면 내려요.
- 점검과 생활 체크: 월간 두뇌 점검(끔·2·4·8주마다), 훈련 뒤 생활 체크(30초), **점수 보여 주기**(기본 꺼짐: 아버지에게는 점수 없이 칭찬만 보여요).
- **저장**을 눌러야 적용돼요. 이미 시작한 오늘의 훈련은 그대로 하고, 바뀐 계획은 다음 훈련부터예요.

**훈련하는 분 화면** (설정 › ○○ 기기 관리 › 화면)
- 글꼴(프리텐다드·노토 산스·휴대폰 기본), 글자 크기(보통·크게·아주 크게·최대), 고대비, 소리 안내와 말 빠르기. 위의 미리보기로 먼저 확인하고 **저장**해요.
- 가족 자신의 폰은 설정 › **내 화면**에서 따로 정해요 (이 폰에만 적용).
- 프리텐다드는 인터넷(jsDelivr)에서 받아요. 한 번 열어 본 뒤에는 오프라인에서도 같은 글꼴이에요. 못 받으면 노토 산스나 휴대폰 기본 글꼴로 보여요.

**훈련하는 분이 보는 화면**
- 하단 메뉴 없이 **큰 버튼 하나**: 오늘 훈련 시작 / 이어서 하기 / 오늘 완료 ✓ (쉬는 날은 "가볍게 해 보기", 점검 날은 "오늘 점검 시작").
- 게임이 끝나면 칭찬과 다음 게임 소개가 나오고, 정한 초 뒤에 **저절로 다음 게임**이 시작돼요(화면을 누르면 멈춰요). 마지막에는 **처음으로** 버튼 하나만 있어요. 생활 체크와 월간 점검은 켜 두었을 때만 이 흐름 안에 나와요.
- 설정은 오른쪽 위 **작은 톱니바퀴** 뒤에 숨어 있어요. 누르면 "가족이 도와줄 때만 열어 주세요" 확인 창이 나와요.

**실시간 현황** (가족 홈): 오늘 아직 전 / 훈련 중(○개 중 ○개, 지금 하는 게임) / 쉬는 중 / 오늘 완료, 게임별 결과(끝나는 대로), 최근 7일 띠, 마지막으로 앱을 본 시간(훈련하는 분 폰이 60초마다 알려 줘요).

**체험 모드**에서는 한 기기에서 관리자와 훈련하는 분을 모두 해 볼 수 있어요. 설정 › 체험 모드의 **훈련하는 분 화면으로 보기** 로 바꾸고, 훈련하는 분 화면의 톱니바퀴 › 설정 › **가족(관리자) 화면으로 보기** 로 돌아와요.

**배포 순서:** 보안 규칙을 먼저 올리고(`firebase deploy --only firestore:rules`, `cd tests && npm test` 통과 확인), 그다음 화면(GitHub Pages)을 올려요. 규칙을 올린 뒤에도 옛 앱은 훈련 기록·대화를 계속 쓸 수 있어요. 처음 한 번은 방 주인이 설정 › 가족 구성원에서 도와줄 가족을 관리자로 정하고, 훈련 계획과 화면을 한 번 저장해 두세요.

## 13. 알림 보내는 방법 고르기 (둘 중 하나)
가족의 응원과 훈련 시간 알림을 폰으로 보내려면 "보내는 곳"이 필요해요.

| | A. Cloud Functions (추천) | B. GitHub Actions |
|---|---|---|
| 요금제 | Blaze (카드 등록, 이 규모는 사실상 무료) | 무료, 카드 불필요 |
| 알림 속도 | 1~3초 | 10~40분 늦을 수 있고 가끔 건너뜀 |
| 비밀 키 | 구글 안에서만 | 서비스 계정 키를 GitHub Secret에 보관 |

### A. Cloud Functions (즉시 알림)
1. Firebase 콘솔 왼쪽 아래 **요금제 업그레이드 → Blaze** 로 바꿔요(카드 등록). 바로 **예산 알림**(예: 월 5,000원)을 설정해요.
2. PC에서:
   ```
   npm i -g firebase-tools
   firebase login
   firebase use 프로젝트ID
   cd functions && npm install && cd ..
   firebase deploy --only functions,firestore
   ```
3. `APP_URL` 을 물으면 `https://내아이디.github.io/brain-walk/` 를 입력해요.

### B. GitHub Actions (무료)
1. Google Cloud 콘솔 › IAM › 서비스 계정에서 서비스 계정을 만들고 `Cloud Datastore User`, `Firebase Cloud Messaging API Admin` 역할을 준 뒤 키(JSON)를 만들어요. (더 간단한 방법: Firebase 콘솔 › 프로젝트 설정 › 서비스 계정 › 새 비공개 키 생성)
2. GitHub **Settings › Secrets and variables › Actions › New repository secret** 에 이름 `FIREBASE_SERVICE_ACCOUNT`, 값에 JSON **전체**를 붙여넣어요. 그 뒤 내려받은 JSON 파일은 지워요.
3. 같은 화면의 **Variables** 탭에 `APP_URL` = `https://내아이디.github.io/brain-walk/` 를 추가해요.
4. **Actions › reminders (push fallback) › Run workflow** 로 시험해요.

> ⚠ 키 파일을 저장소에 절대 올리지 마세요. (`.gitignore` 가 막아 주지만 직접 확인하세요.)
> ⚠ 저장소에 60일 동안 변화가 없으면 GitHub가 예약 실행을 멈춰요. 메일이 오면 Actions에서 다시 켜 주세요.
> 둘을 함께 켜 둬도 안전해요. 같은 알림이 두 번 가지 않아요. A(Cloud Functions)를 배포하면 그 `tick` 이 5분마다 `ops/pushTick` 에 "살아 있음"을 남기고, B(Actions)는 그 기록이 20분 안이면 아무것도 보내지 않고 쉬어요(로그: `fallback idle`). Functions 가 멈추면 B 가 다음 실행부터 다시 보내요. 시험으로 B 를 강제로 돌리려면 `FORCE=1`.

## 13-1. AI 문제 은행·리포트 (Cloud Functions)
설계: `DESIGN-AI.md` (승인본). 앱 화면은 아직이에요(다음 작업). 서버는 **Cloud Functions 2세대, 지역 asia-northeast3**(Firestore 서울과 같은 곳)예요. 코드: `functions/ai/`.

**무엇이 어디서 돌아가나**
| 함수 | 언제 | 하는 일 |
|---|---|---|
| `aiRead` (HTTPS GET) | 루틴이 부를 때 | `?doc=current` 가명 집계 · `?doc=bankNeeds` 만들 문항 수 · `?doc=job&job=<id>` 깨우기 작업과 그 집계. 그 밖은 400 |
| `aiSubmit` (HTTPS POST) | 루틴이 부를 때 | 결과 한 건(`items` 또는 `report`)을 대기실(`aiInbox`)에 써요. 본문 512KB, 한 시간 20건, 모양 검사 |
| `aiOnInbox` | 대기실에 문서가 생기면 즉시 | 검사기(정답 재계산·금지어·개인정보·중복·검사 문항 지문·품질 기록·하루 400개) → 은행/거절 기록 → 가족 묶음·필요 수 갱신. 리포트는 숫자 자리표시자·신호등 검사 → `aiReports`(떨어지면 간단판) → 텔레그램 |
| `aiOnItemLog` | 문항 기록이 생기면 | 문항 사용 표시, 모호 의심 격리, 묶음 갱신 |
| `aiOnProgress` | 오늘 코스가 끝나면 | 다시 집계·신호 계산 → 새 주황 신호면 리포트 루틴을 바로 깨워요(하루 2번, 같은 신호 7일, 20:00–08:00 제외, 다시 시도 안 함, 실패하면 간단판 + 규칙 알림) |
| `aiDaily` | 매일 06:50 | 주간 통계, 신호(S1–S6), 가명 집계, 기준·앵커 묶음, 훈련 묶음, 필요 수 |
| `aiTgFlush` | 매일 08:00 | **02:00–08:00 에는 어떤 텔레그램도 보내지 않아요.** 그 사이에 생긴 알림과 08:00 전의 아침·주간 리포트 알림은 `tgOutbox` 에 모였다가 08:00 에 **한 통**으로 가요(같은 종류는 한 줄로, `aiTick` 과 겹쳐도 한 번만, 3번 실패하면 버려요) |
| `aiTick` | 10분마다 | 남은 텔레그램 대기열 보내기(08:00 뒤 뒷받침), 08:30까지 리포트가 없으면 간단판, 깨운 뒤 90분 동안 리포트가 없으면 간단판, 문제 만들기 2일 멈춤 알림, 예정에 없던 키 사용 알림 |
| `aiPurge` | 매일 04:30 | 보관 기한(문항 기록 2년, 리포트·통계·신호·메모 5년, 은퇴 문항 1년)과 지운 가족방의 남은 자료. 대기실·집계·작업·거절 기록은 Firestore TTL(`expireAt`)이 지우고 이건 뒷받침이에요 |
| `aiOnReview` | 관리자가 검토 결정을 쓰면 | 옛날 이야기 내보내기, 문항 은퇴·신고 |

**루틴 인증 (고정 키 하나):** 루틴은 Firestore 에 직접 접근하지 않고 위 두 함수만 불러요. 키는 48글자 무작위 값이고, Firestore `aiConfig/main.routineKeyHash` 에는 **sha256 만** 둬요(원래 키는 DB·코드·로그·git 어디에도 없어요). 함수는 `Authorization: Bearer <키>` 를 sha256 해서 `timingSafeEqual` 로 비교해요. 해시가 없거나 64글자 16진수(sha256)가 아니면 503, 키가 틀리면 401. 설정은 60초 동안 기억했다가 다시 읽어서, 해시를 바꾸거나 지우면 배포 없이 60초 안에 막혀요. 보안 규칙은 AI 를 위해 아무 계정에도 문을 열지 않아요.

**비밀값 (Secret Manager):** `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `ROUTINE_REPORTER_URL`, `ROUTINE_REPORTER_TOKEN`. 코드·로그에 없어요. 함수 배포 **전에** 네 개가 모두 있어야 해요(루틴 API 트리거를 만들기 전이면 두 ROUTINE 값은 `unset` 으로 넣어 두면 깨우기 대신 규칙 알림만 가요).

**배포 순서** (Blaze, `firebase login`, `firebase use brain-walk`)
```
cd functions && npm ci && npm test && cd ..
cd tests && npm install && npm test && npm run test:ai && cd ..
firebase functions:secrets:set TELEGRAM_BOT_TOKEN
firebase functions:secrets:set TELEGRAM_CHAT_ID
firebase functions:secrets:set ROUTINE_REPORTER_URL      # 아직이면 unset
firebase functions:secrets:set ROUTINE_REPORTER_TOKEN    # 아직이면 unset
echo 'APP_URL=https://albatrus0102.github.io/brain-walk/' > functions/.env.brain-walk   # git 에 안 올라가요(.gitignore)
firebase deploy --only functions,firestore:rules,firestore:indexes
gcloud auth application-default login
cd functions && node ai/tools/set-routine-key.mjs --project brain-walk --family <가족방 id> --enable --out ~/bw-routine-key.txt
```
이 배포는 기존 알림 함수(`onFamilyMessage`, `tick`, `dailyPurge`)도 함께 올려요(13번 A). 그 뒤 GitHub Actions 알림은 저절로 쉬어요.
함수 주소: `https://asia-northeast3-brain-walk.cloudfunctions.net/aiRead`, `…/aiSubmit` (2세대라 `…run.app` 주소도 함께 생겨요). 키 없이 부르면 401 이 나와야 해요.
루틴 쪽 준비(전용 환경, 네트워크 허용 한 줄, 키 파일, 루틴 두 개, API 트리거)는 `brain-walk-ai` 저장소의 `SETUP.md` 에 있어요. API 트리거를 만든 뒤 `ROUTINE_REPORTER_URL/TOKEN` 을 다시 넣고 `firebase deploy --only functions:aiOnProgress`.

**한 번만 할 일·조정:** 기준선 4주가 끝나고 6~8주차에 `node ai/tools/simulate.mjs --firestore --write` 로 신호 문턱을 맞춰요(거짓 주황 1년 1회 이하). 키는 6개월마다 `set-routine-key.mjs` 로 바꿔요(급할 때 `--revoke`).

## 15. 기기를 바꿨을 때 / 잃어버렸을 때
- **기기를 바꿀 때:** 옛 폰의 설정 › **다른 기기로 옮기기** → 나오는 코드(약 25분, 한 번만 쓸 수 있어요)를 새 폰의 첫 화면 **기기 옮기기 코드가 있어요**에 입력해요. 기록과 가족 연결이 그대로 이어져요.
- **폰을 잃어버렸을 때:** 관리자의 폰에서 설정 › **가족 구성원** → 잃어버린 분의 이름 › **새 기기 연결 코드 만들기**를 누르면 그분의 새 폰용 코드가 나와요. 새 폰의 첫 화면 **기기 옮기기 코드가 있어요**에 입력해요. ("다른 기기로 옮기기"로 만든 코드는 *만든 사람 자신*으로 연결되니 쓰지 마세요.) 다른 사람의 코드는 **관리자만** 만들 수 있어요(새로 들어온 사람이 곧바로 아버지로 행세하는 것을 막아요). 설정 › 가족 구성원에서 그 사람을 눌러 **새 기기 연결 코드 만들기**를 해요. 그 뒤 새 폰의 설정 › **연결된 기기**에서 잃어버린 폰의 연결을 끊어요.
- 브라우저 데이터를 지우거나 앱을 지우면 그 기기의 로그인이 사라져요. 이때도 위 방법으로 복구해요.

## 16. 문제 해결
- **알림이 안 와요:** 아이폰은 *홈 화면에 추가한 앱*에서만 와요(iOS 16.4 이상). 설정 › 알림 허용 상태와 앱 설정의 "알림 받기" 스위치를 확인해요. 차단했다면 폰 설정에서 이 앱의 알림을 허용한 뒤 앱에서 다시 켜 주세요.
- **"관리자 설정이 필요해요"가 떠요:** 9번을 확인해요. `REPLACE_ME` 가 남아 있으면 이 화면이 나와요.
- **코드가 안 맞아요:** 7일이 지났거나 새로 만들어진 경우예요. 가족에게 새 코드를 부탁해요. `0/O`, `1/I` 는 코드에 없어요.
- **"연결하지 못했어요"가 떠요:** 인터넷을 확인하고, 익명 로그인(5번)과 Firestore(6번)가 켜져 있는지 봐요.
- **새 버전이 반영되지 않아요:** 앱을 완전히 닫았다가 다시 열어요. "새 버전이 있어요" 창이 뜨면 업데이트를 눌러요.

## 17. 개인정보와 삭제

- 이 앱은 진단 도구가 아니에요. 점수가 계속 낮아지면 병원과 상담하세요.

- 파일을 더하거나 지우면 `node tools/shell-list.mjs --write` 로 `sw.js` 의 캐시 목록을 갱신해요(`npm run check --prefix tests` 가 확인해 줘요).

- 아이콘 다시 만들기: `python3 tools/make-icons.py` (Pillow).

### 월간 점검의 자체 과제 (브랜드·규준·기준점 없음)
두뇌 건강 점검의 2부분(약 7분)에 일반적인 심리 실험 패러다임을 *이 앱이 직접 만든* 과제로 넣었어요. 검사 이름이나 공개 검사의 문항·낱말 목록·화면을 쓰지 않았고, 기준점도 없어요. 결과는 "처음 점검(기준선)과 비교한 변화"로만 보여 줘요. 점수 환산식은 이 앱 자체의 눈금일 뿐 규준이 아니에요.

| 과제 | 영역 | 방식 |
|---|---|---|
| 낱말 기억하기 (바로 / 조금 뒤) | 기억력 | 자체 낱말 10개(3개 판을 달마다 돌려 씀)를 보여 주고, 글자를 치지 않고 "기억나는 낱말 고르기"(보기 20개)로 회상. 점검 맨 끝에 같은 낱말을 한 번 더 물어봐요. 고르기 방식이라 순수한 자유 회상이 아니에요. |
| 점 잇기 (숫자 / 숫자와 글자) | 반응 속도 / 계산·순서 | 1→2→3… 과 1→가→2→나… 를 시간 재며 터치 |
| 숫자 기억하기 | 집중력 | 무작위 숫자열을 앞으로·거꾸로 따라 누르기 |
| 반응 속도 | 반응 속도 | 신호가 바뀌면 누르기 5번의 중앙값 |
| 색 고르기 | 집중력 | 글자 색 맞히기(색-글자 간섭), 큰 색 버튼 |
| 동물 이름 대기 (1분) | 날짜·시간 감각(말) | 마이크 없이 가족이 +1 을 누르거나 끝난 뒤 개수 입력 |

기존 다섯 영역 점수는 그대로예요(같은 영역 게임·과제 점수의 평균). 한 번에 약 15분이고, 1부분(기존 게임, 약 8분)을 마친 뒤 "내일 이어서 하기"로 두 번에 나눠 할 수 있어요(3일 안에). 과제 상세는 가족 기록의 "점검 과제 상세"에 보여요(`taskRuns`).

### 일상생활 체크 · 잠 기록 · 시계 그리기 (모두 자체 제작, 점수 기준 없음)
- **일상생활 체크**: 가족이 8문항(약 챙겨 먹기, 돈 계산, 전화, 길 찾기, 일정 기억 등)에 답해요. K-IADL·S-IADL 등 공개 도구의 문항이 아니라 이 앱이 직접 만든 문항이에요. 설문과 같은 방식으로 저장되고(가족 전용) 점수 변화만 보여 줘요.
- **잠 기록**: 생활 체크 안의 "잠을 더 자세히 적기(선택)"에서 잠든 시각, 일어난 시각, 깬 횟수를 적어요. 가족 기록에서 최근 7일을 볼 수 있어요. PSQI 같은 검사는 쓰지 않았어요.
- **시계 그리기**: 훈련하는 분이 "11시 10분을 가리키는 시계를 그려 주세요"를 손가락으로 그려요. 작은 PNG(data URL, 200KB 이하로 줄임)로 저장하며 **자동 채점은 하지 않아요.** 그림은 가족만 볼 수 있고(훈련하는 분은 쓰기만 가능), 가족은 시간 순서대로 나란히 볼 수 있어요.

### 병원 검사 기록
- **병원 검사 기록** (가족 전용): 가족이 결과지의 점수를 옮겨 적어요. 검사(CIST, MMSE-DS, K-MMSE, MoCA/K-MoCA, SNSB, CERAD-K, CDR, GDS(전반 퇴화), 기타), 날짜, 점수와 만점(검사별로 CIST·MMSE-DS·K-MMSE·MoCA 30, CDR 3을 미리 채움), 기관, 결과 요약, 메모(500자), 기록한 사람을 저장해요(`clinicalTests`). 필수 칸만 먼저 보이고 나머지는 "더 입력하기" 안에 있어요. 가족 기록 화면에 검사별 점수 변화와 최근 결과가 보여요. 앱은 CIST 등 **어떤 검사의 문항이나 내용도 담고 있지 않아요**(저작권·의료기기 문제). 검사는 병원에서 받아요.
- **채팅에 공유**(선택): 기록 카드를 가족 대화방에 올려요. 훈련하는 분도 대화방을 보므로 "아버지도 대화방을 보세요. 공유할까요?" 확인을 먼저 받아요.

### 화면 구성 원칙
- **훈련하는 분**: 하단 메뉴는 홈·훈련·대화 3개. 홈에는 큰 버튼 하나("오늘의 훈련 시작" / "이어서 하기" / "오늘 완료 ✓")와 응원·생활 체크 카드만 있어요. 12주 프로그램, 월간 점검, 설문, 시계 그리기는 "훈련" 탭에 있어요. 설문·기록·검사 결과는 보이지 않아요(가족 전용).
- **가족**: 홈·기록·점검·대화 4개. 설문, 일상생활 체크, 시계 그림, 병원 검사 기록은 "점검" 탭에서 한 가지씩 골라요.
- 한 화면에 한 가지 일, 주 버튼은 아래 고정·가로 가득. 아이콘에는 글자 이름을 함께 써요(뒤로·설정). 영역 이름은 쉬운 말로 바꿨어요(집중력, 계산·순서, 날짜·시간 감각, 빠른 반응).
